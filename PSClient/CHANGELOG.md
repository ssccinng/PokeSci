# PSClient 重构日志

## 版本 2.0.0 - 重大重构

### 概述
基于原始的 PokePSCore 项目进行了全面重构，提升了代码质量、可维护性和可扩展性。

### 主要改进

#### 1. 架构优化
- **模块化设计**: 将代码按功能划分为不同的命名空间和文件夹
- **清晰的职责分离**: 每个类都有明确的职责
- **更好的封装**: 改进了数据模型的封装性

#### 2. 框架升级
- **目标框架**: 从 .NET 6.0 升级到 .NET 9.0
- **现代 C# 特性**: 使用最新的 C# 语法和特性
- **改进的空值处理**: 更好的nullable引用类型支持

#### 3. 代码组织

##### 新的项目结构
```
PSClient/
├── Core/                    # 核心数据类型
│   ├── ChooseData.cs       # 选择数据基类
│   ├── MoveChooseData.cs   # 招式选择数据
│   └── SwitchData.cs       # 交换选择数据
├── Models/                  # 数据模型
│   ├── BattleData.cs       # 对战数据模型
│   ├── PSBattlePokemon.cs  # 对战宝可梦模型
│   └── UserModels.cs       # 用户相关模型
├── Client/                  # 客户端实现
│   ├── PSClient.cs         # 主客户端类
│   └── PSClientCommands.cs # 命令扩展
├── Battle/                  # 对战管理
│   ├── PSBattle.cs         # 对战管理类
│   └── PSBattleLogic.cs    # 对战逻辑处理
├── Extensions/              # 扩展方法
│   └── PSClientExtensions.cs
├── Utilities/               # 工具类
│   └── PSTools.cs
├── Exceptions/              # 异常定义
│   └── PSClientExceptions.cs
└── Examples/                # 示例代码
    └── SimpleExample.cs
```

- **详细信息**: 提供更多的错误上下文信息

### 迁移指南

#### 从 PokePSCore 迁移到 PSClient

1. **更新引用**
   ```csharp
   // 旧版本
   using PokePSCore;
   
   // 新版本
   using PSClient.Client;
   using PSClient.Models;
   using PSClient.Core;
   ```

2. **客户端创建**
   ```csharp
   // 旧版本
   var client = new PSClient(userName, password);
   
   // 新版本 (相同)
   var client = new PSClient(userName, password);
   ```

3. **事件处理**
   ```csharp
   // 旧版本
   client.RequestsAction += (battle) => { };
   
   // 新版本
   client.OnRequestAction += (battle) => { };
   ```

4. **行动选择**
   ```csharp
   // 旧版本
   await battle.SendMoveAsunc(new MoveChooseData(1));
   
   // 新版本
   await battle.SendMoveAsync(new MoveChooseData(1));
   // 或使用扩展方法
   await battle.SendMoveAsync(PSClientExtensions.Move(1));
   ```
